# Complete Java 17+ Curriculum Repository (`01_Java_Basics` & `02_Java_OOP`)

Welcome to the complete **54-Lesson Java Curriculum Repository**. Every lesson folder contains four structured files:
1. **`README.md`**: Beginner-friendly technical explanation, architecture diagrams, syntax rules, common pitfalls, and real-world use cases.
2. **`Example.java`**: Clean, thoroughly commented, runnable Java 17+ code demonstrating every concept in that lesson.
3. **`PracticeSheet.md`**: Progressive coding problems (Easy, Medium, Hard) with input/output examples and edge-case hints.
4. **`Exercise.java`**: Complete, runnable solutions for every problem in `PracticeSheet.md` with detailed `// WHY WE USED THIS WAY:` explanations.
