# Lesson 24: Revision OOP — Part 3 (OOP Practice Project Part 3: Interfaces, Enums & Exception Handling)

## 1. Project Overview: Hospital Pharmacy & Triage Compliance Subsystem
In **Part 3 (Lesson 24)** of our OOP Revision series, we combine:
1. **Rich Enums (`TriageSeverity`)**: Storing emergency response SLA minutes and priority codes inside type-safe enum constants.
2. **Multiple Interfaces (`Prescribable`, `HipaaAuditable`)**: Modeling cross-cutting capabilities with `abstract` and `default` methods.
3. **Custom Checked Exceptions (`ControlledSubstanceException`)**: Enforcing strict compile-time safety (`throws` and `try-catch-finally`) when dispensing regulated medications.
