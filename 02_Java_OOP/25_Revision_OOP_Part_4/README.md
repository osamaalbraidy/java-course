# Lesson 25: Revision OOP — Part 4 (OOP Capstone Project: Full Multi-Class Management System Using `ArrayList`)

## 1. Capstone Architecture Overview
In **Part 4 (Lesson 25)**, we bring together **every single OOP pillar and Java feature** from Module 2 into a cohesive **Multi-Class Cloud Fleet & Billing Management System** powered by **`ArrayList`**:
- **Encapsulation, Chained Constructors & `static` ID Generation** (`CloudResource`)
- **Abstract Classes, Inheritance & Method Overriding** (`ComputeNode`, `StorageCluster`)
- **Interfaces (`Billable`, `Monitorable`)**
- **Rich Enums (`ServiceTier`)**
- **Custom Checked Exceptions (`QuotaExceededException`)**
- **`ArrayList<CloudResource>` Dynamic Management Repository (`CloudFleetManager`)**
