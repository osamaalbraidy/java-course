# Lesson 26: Revision — Java Basics & OOP Cumulative Review Sheet

## 1. Comprehensive Curriculum Master Reference
Congratulations on completing all **54 lessons** across **Module 1 (`01_Java_Basics`)** and **Module 2 (`02_Java_OOP`)**!

This final lesson serves as your **Cumulative Master Cheat Sheet** and end-to-end synthesis of both modules:

### Module 1 (`01_Java_Basics`) Master Checklist
1. **JVM Architecture**: Source Code (`.java`) $\xrightarrow{\text{javac}}$ Bytecode (`.class`) $\xrightarrow{\text{JVM}}$ Native Machine Code.
2. **8 Primitive Types**: `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean` (plus `String` reference type).
3. **Type Casting & Operators**: Implicit widening vs. explicit narrowing `(int)`; integer division (`7 / 2 == 3`) vs. floating-point (`7.0 / 2 == 3.5`); modulo `%`; prefix `++x` vs. postfix `x++`.
4. **Conditionals**: `if / else if / else`, short-circuit `&&` and `||`, `.equals()` for Strings, and Java 17 `switch` expressions (`->` and `yield`).
5. **Loops**: Pre-test `while` (counter, boolean flag, sentinel), post-test `do-while` (CLI menus), `for` and nested `for` loops, `break` and `continue`.
6. **Methods & Arrays**: Pass-by-value, scope & shadowing, method overloading, 1D arrays (`int[]`), and 2D matrices (`int[][]`).

### Module 2 (`02_Java_OOP`) Master Checklist
1. **Encapsulation & Classes**: `private` fields, `public` getters/setters with validation, `this` keyword, UML diagrams, overloaded constructors chained with `this(...)`, and `static` class members.
2. **Object References**: Passing objects to methods, overriding `.equals()` & `.toString()`, and shallow vs. deep copy constructors.
3. **Inheritance & Polymorphism**: `extends`, `super(...)`, `@Override`, upcasting, dynamic method dispatch, `instanceof` pattern matching, `protected`, and `final`.
4. **Contracts, Enums, Exceptions & Collections**: `abstract` classes vs. `interface` (`implements`), rich `enum` types, `try-catch-finally` (`throw` / `throws`), and dynamic `ArrayList<E>`.
